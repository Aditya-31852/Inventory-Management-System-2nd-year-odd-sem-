# Stockroom — Inventory Tracking System

A responsive frontend project for tracking inventory, stock levels, locations and low-stock alerts.

## Features
- Sign in and account creation
- Browser-based session using localStorage
- Inventory dashboard
- Total items, units, low-stock and location statistics
- Add, edit and delete inventory items
- Search by item, SKU or location
- Filter low/healthy stock
- Responsive UI
- No backend required for demonstration

## Tech Stack
- HTML5
- CSS3
- JavaScript (ES6+)
- Browser LocalStorage API

## Run
Open `index.html` in a modern browser.

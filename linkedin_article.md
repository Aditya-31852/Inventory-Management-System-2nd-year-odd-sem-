# Stockroom: A Simple Inventory Tracking System

Managing inventory through scattered spreadsheets can make it difficult to know what is available, where it is stored and when stock needs to be replenished. To address this problem, I developed **Stockroom**, a lightweight inventory tracking web application.

## What the project does

Stockroom provides a single dashboard where users can:

- Sign in or create an account
- View total inventory items and units
- Monitor low-stock items
- See storage locations
- Add, edit and delete inventory records
- Search by item name, SKU or location
- Filter between healthy and low stock

## Technology used

The project was built using **HTML5, CSS3 and JavaScript**. Browser `localStorage` is used to demonstrate authentication/session handling and inventory persistence without requiring a backend server.

## What I learned

While building Stockroom, I practiced:

1. Semantic HTML and responsive page structure
2. CSS layouts and responsive design
3. DOM manipulation and event handling
4. JavaScript CRUD operations
5. LocalStorage-based persistence
6. Form validation and user interaction
7. Organizing a project in a Git repository

## Future improvements

The next version can add a real backend and database, role-based access, barcode scanning, inventory movement history, cloud deployment and stronger authentication.

## Conclusion

Stockroom demonstrates how frontend technologies can be combined to create a practical inventory management interface. The project also gave me hands-on experience in turning a real-world requirement into a working web application.
